# Security and privacy

This repository is a public demonstration of Haber. It must contain synthetic data only.

Do not open a public issue containing credentials, bank statements, account numbers, transaction exports, names, email addresses, or other financial information. If you discover a vulnerability, contact the repository owner privately through their GitHub profile and include only the minimum technical detail needed to reproduce it.

Before every release:

1. Run the secret scan and build checks.
2. Confirm that every `.env*` file is ignored.
3. Confirm that public fixtures contain no real transactions or identifiers.
4. Publish from a clean history that has never contained private financial data.
